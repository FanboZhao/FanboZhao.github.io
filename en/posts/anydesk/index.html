Fixing an AnyDesk connection on Ubuntu 22.04

A troubleshooting note on Wayland, Xorg, and a display_server_not_supported error.

2025.11.221 min readFanbo Zhao
On this page

The issue

When connecting remotely to an Ubuntu 22.04 computer using AnyDesk, the connection failed with this message:

The session has ended.
Status: display_server_not_supported

Some security-related settings on the Ubuntu computer also could not be unlocked.

Investigating the display server

Ubuntu may be running Wayland instead of Xorg. In this setup, switching to Xorg resolved the AnyDesk connection issue.

Check the current session type:

echo $XDG_SESSION_TYPE

Switch to Xorg for the session

  1. Log out of Ubuntu without shutting down the computer.
  2. On the login screen, choose the gear icon and select Ubuntu on Xorg.
  3. Log back in and try the connection again.

Make Xorg the default, if needed

Edit the GDM configuration:

sudo nano /etc/gdm3/custom.conf

Find the following line, which may be commented out:

#WaylandEnable=false

Remove the # so it becomes:

WaylandEnable=false

Save the file and restart the computer. GDM will use Xorg by default.
