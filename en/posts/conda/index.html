A practical Conda command reference

Everyday commands for creating, managing, and reproducing Python environments.

2025.11.101 min readFanbo Zhao
On this page

  • Activate and deactivate
  • List and remove environments
  • Install and remove packages
  • Update packages

Create an environment

# Create an environment with a specific Python version
conda create -n myenv python=3.10

# Install packages while creating the environment
conda create -n myenv python=3.10 numpy pandas

Activate and deactivate

conda activate myenv
conda deactivate

List and remove environments

conda env list

# Remove the environment and all packages inside it
conda remove -n myenv --all

Install and remove packages

conda install numpy
conda install numpy=1.26
conda remove numpy

Update packages

conda update numpy
conda update conda
conda update --all

Export and recreate an environment

# Export the environment, including channel information
conda env export > environment.yml

# Recreate the environment from the exported file
conda env create -f environment.yml

Clone an environment and inspect packages

conda create --name newenv --clone oldenv
conda list
